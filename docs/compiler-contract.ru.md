# Согласование контрактов компиляторов

`Compiler` остаётся CLI-реализацией, а `EmbeddedCompiler` — реализацией embedded-протокола. На этом этапе классы не переименовываются и новый API версии 2 не вводится.

## Общий контракт

Обе реализации предоставляют совместимое поведение для следующих возможностей:

- хранение и получение `Options`;
- fluent-вызовы `setOptions()`;
- обработка пустой строки;
- компиляция в expanded и compressed стилях;
- компиляция indented-синтаксиса;
- компиляция строк и файлов;
- пути загрузки модулей;
- условная запись скомпилированных файлов;
- исключения для отсутствующих файлов;
- режимы вывода source map.

Общие ожидания находятся в `tests/Feature/CompilerContractTest.php` и выполняются для обеих реализаций.

## Намеренные различия реализаций

Следующие возможности остаются специфичными для `EmbeddedCompiler`:

- повторное использование долгоживущего процесса Dart Sass;
- транспортные повторы и управление жизненным циклом процесса;
- сбор структурированных объектов `LogEvent`;
- обработчики логов в реальном времени;
- опция embedded-протокола `verbose`.

CLI-реализация продолжает предоставлять защищённые точки расширения для управления процессом и построения аргументов. На этом этапе контракт наследования не изменяется.

## Принятые решения

### Настройки уровня метода

Настройки, переданные непосредственно в `compileString()` или `compileFile()`, переопределяют только явно заданные значения и наследуют остальные значения из настроек экземпляра, установленных через конструктор или `setOptions()`. Значения `false` и `[]` считаются явными переопределениями; только `null` означает наследование.

Объединение централизовано в `Options::withOverrides()` и используется обеими реализациями.

### Ввод, содержащий только комментарии

Корректный Sass-код, который не генерирует CSS, возвращает пустую строку. Отсутствие CSS не считается ошибкой при успешном завершении Dart Sass.

### Исключения

Обе реализации используют иерархию исключений пакета и гарантируют стабильную категорию ошибки. Транспортно-зависимый текст, stderr и диагностические подробности не обязаны совпадать дословно.

### Приоритет `url` и `sourceFile`

`url` является основным каноническим идентификатором исходника. `sourceFile` используется как резервное значение, если `url` не задан.

## Критерии завершения

- общая контрактная матрица проходит для обеих реализаций;
- намеренные различия явно задокументированы;
- случайные семантические расхождения устранены;
- публичные имена и роли классов не изменены;
- тесты проходят на PHP 8.2–8.5;
- покрытие остаётся на уровне 100%;
- PHP CS Fixer, Rector и sass-spec проходят успешно.
